## 2. Как запустить

```bash
cd C:\Users\malik\esenin-dashboard
npm run build      # пересобрать dist/
npm run serve      # http://localhost:4173
npm run check      # проверка внутренних ссылок
```

Открывать только через `http://localhost:4173`, не через `file://` — в проекте абсолютные пути к CSS/JS.

## 3. Архитектура

- Генератор: `scripts/build.mjs` (Node.js, без зависимостей).
- Данные: `data/*.json` + `content/*.md`.
- Шаблоны и стили: `src/styles.css`, `src/app.js`.
- Сборка очищает `dist/` и генерирует страницы, `search.json`, `sitemap.xml`, `robots.txt`.
- Версионирование ассетов: `?v=<hash>` — при изменении CSS/JS кэш браузера сбрасывается автоматически.
- Домен задаётся в `site.config.json` (`siteUrl`), сейчас заглушка `https://esenin.example`.

## 4. Принятые решения

- Полные тексты произведений (общественное достояние), с указанием страницы-источника.
- Фотографии — только Wikimedia Commons (PD/CC) с атрибуцией.
- Научные работы — только метаданные и аннотации, без полных текстов.
- Спорные факты — отдельный раздел «Версии», в основных текстах только подтверждённое.
- Без комментариев и пользовательских данных.
- Только русский язык; i18n заложена в структуру, но не реализована.
- Статика + Git, без CMS и без серверной БД.

---

## 5. Известные ограничения

1. Поиск ищет по названию и первой строке, не по полному тексту.
2. Нет отдельной A–Z-страницы (есть сортировка по алфавиту).
3. Нет CMS-админки — правки в JSON/Markdown + пересборка.
4. `siteUrl` — заглушка, заменить перед публикацией.
5. JSON-LD только `Person` на всех страницах; для произведений не добавлен `CreativeWork`.
6. Нет автотестов вёрстки и скриншот-регрессии.

## 6. Следующие шаги (приоритет)

1. Полнотекстовый индекс по 410 текстам с ленивой загрузкой.
2. A–Z-указатель и «случайное произведение».
3. `CreativeWork` / `ScholarlyArticle` JSON-LD на страницах произведений и научных работ.
4. Подключение headless CMS (Decap) для редактора.
5. Скриншот-регрессия и проверка Lighthouse в CI.
6. Замена домена, деплой на хостинг, аналитика.
