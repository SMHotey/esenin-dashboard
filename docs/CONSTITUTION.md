# Конституция проекта «Сайт о Есенине»

Принципы, которые действуют на любой задаче проекта. План обязан им соответствовать;
ревью плана и ревью шага называют нарушенный пункт номером.

1. **Тексты — общественное достояние, источник указан.** Произведения выкладываются с
   указанием источника (Викитека, ФЭБ, полное собрание сочинений). Оригинальный текст
   не редактируется и не сокращается.
2. **Разделы пишем свои.** Чужие статьи, очерки, музейные описания и энциклопедические
   справки не копируются; факты берутся со ссылкой на источник, спорное выносится в
   раздел «Версии» с уровнями достоверности.
3. **Цены книг на сайте не публикуются.** Партнёрские ссылки идут с маркировкой
   «Реклама…», `erid` и метками магазина; партнёрские программы — только официальные.
4. **Никаких зависимостей в рантайме.** Сборка — Node без пакетов; сторонний код
   вендорится в репозиторий файлом с сохранённой лицензией, а не ставится из npm.
5. **`npm run verify` до пуша.** Сборка, ссылки, аудит текстов и прод-проверки: норма —
   0 ошибок и 0 предупреждений. Красный verify означает «не готово», а не «посмотрим потом».
6. **Правка переносится по серии.** Изменение или найденный баг в одном сайте о поэтах
   проверяется и повторяется в остальных проектах серии (Есенин, Бунин, следующие).
7. **Читатель по умолчанию ничего не теряет.** Новые режимы, эффекты и оформление
   включаются по выбору и полностью откатываются; тёмная тема — по умолчанию;
   клавиатура и скринридеры работают без мыши.
8. **Данные — единственный источник истины.** Содержимое живёт в `data/*.json` и
   `content/*.md`; сборка их читает и не переписывает; руками в `dist/` не правится.
9. **Без выдуманных фактов и выдуманных результатов.** Нет подтверждения — нет
   утверждения; нет прогона — нет отчёта о прогоне.
10. **Доступность и скорость — часть готовности.** Страница работает без JS в разумном
    объёме, вес ассетов ограничен, лишнее не грузится на всех страницах ради функции
    меньшинства.
