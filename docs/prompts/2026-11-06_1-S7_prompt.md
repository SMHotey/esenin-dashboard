## 4. Решения (приняты постановкой; менять нельзя, оспаривать — вопросом владельцу)

- **R1. Матрица — автостенд, а не рассказ.** Основной инструмент — CDP-стенд Chrome (`scratch/s7-matrix.mjs`, образец F15/F16): `Emulation.setDeviceMetricsOverride` на каждую ширину, `localStorage` для темы и кегля, клик по кнопке книги, замеры из DOM. Ручное «глазами» остаётся только там, где его не заменить: типографика блоков (`part`/`date`/`head`/`verse`) — четыре скриншота и перечень увиденного (T5, G5). Всё остальное — числа из стенда.
- **R2. Три кегля книги вводятся этим шагом:** значения **18/20/22 px** (документ §5:160), значение по умолчанию 20, ключ `localStorage` — `book.size.v1` (в стиле `book.view.v1` из S2). Кнопки `A−` и `A+` с `data-book-size="smaller"` и `data-book-size="bigger"`, `aria-label` «Меньше шрифт» и «Больше шрифт» (в книге работает клавиатура и скринридер — S5), границы гасятся через `disabled` (стиль уже есть: `book.css:50`). Смена кегля = пересборка книги на ту же долю, как у смены вида (`setView`, `src/book/book.js:692-706`). Обязательное следствие: `--book-size` переезжает с листа `[data-book] .page` на секцию `[data-book]` — иначе объявление на `.page` (F5) перебьёт наследование и кегль не сменится.
- **R3. Ширины: страница не вылезает за окно.** Требование — на 320 px и в развороте при 768-1023 px горизонтального вылета нет ни в одном состоянии матрицы (G4). Переписывать геометрию в JS и трогать пагинацию нельзя: `findCut`/`paginate` (`:350-419`) — чужой проверенный код S3, регресс нарезки = стоп S5.
- **R4. Сравнение с локальным `dist` запрещено (F10).
