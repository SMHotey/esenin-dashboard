## 1. Роль и цель

Ты — программист шага S4 плана «Книжный режим». S3 сделал настоящий лист на вендоренном StPageFlip, нарезку текста, кнопки «‹/›», перетаскивание и позицию чтения. Твоя работа — озвучить перелистывание: короткий синтезированный WebAudio-шорох, разный вперёд и назад, с выключателем «Звук», который помнит выбор; при отказе WebAudio книга листается молча и не ломается. Звуковых файлов в репозитории не появляется.

Контракт шага из §S4 (`docs/plans/1-book-reader.md:91-96`):

- **C1.** Перелистывание озвучено коротким синтезированным шорохом, вперёд и назад по-разному.
- **C2.** Есть выключатель, он помнит выбор в `localStorage`.
- **C3.** Звук синтезируется WebAudio, файлов `.mp3`/`.wav` в репозитории нет.
- **C4.** При отказе WebAudio книга продолжает листаться молча.
- **C5.** `npm run verify` → 0 ошибок и не больше одного пре-существующего предупреждения — «очередь журнала публикаций»; чужое предупреждение не чинится (S5), строка `ПРОВЕРКА …` приводится в отчёт как есть. Требование «0 предупреждений» на HEAD недостижимо. Плюс инструментальные доказательства §5 (на слух агент не проверяет — В1).
- **C6.** Постановка прошла `check_task_prompt.py` (сделано постановщиком, G5).

## 3. Расхождения плана с деревом — названы, а не сглажены

1. **`flippingTime: 0` невозможен.** §2.5 документов (`docs/BOOK-READER-PLAN.md:170-171`) требует при `prefers-reduced-motion` ставить `flippingTime: 0`, но библиотека 2.0.7 бросает `Error("Invalid flipping time")` на значении ≤ 0 (F4.10). Принято `flippingTime: 1` (минимальное допустимое) — анимация укладывается в один-два кадра, «смены страницы без анимации» это достигает, а падения конструктора не даёт. R10.
2. **Жест из G4.6 «120 px влево» лист не переворачивает.** `stopMove()` переворачивает только при `calc.getPosition().x <= 0` (F4.11), а позиция считается от центра блока. Поэтому жест задан иначе: нажатие в правой части сцены и движение влево **через центр** с замером фактического порога (G4.6, T4).
3. **База бюджета 18 258 байт устарела.** На HEAD 29 390 (F9), бюджет 20 480 превышен до начала S4 — гейт «прирост ≤ 1,5 КБ» считается от 29 390, долг бюджета фиксируется в отчёте, а не «оптимизируется» в этом шаге (В2, S7).
4. **Адреса S2-дерева после S3 съехали.** В прошлой редакции `buildSection` был :159-222, `open()` :226-266 — на HEAD это :390-445 и :490-501, файл вырос с 290 до 526 строк. Все адреса этой постановки — от HEAD `6d67afa`; расхождение адреса — повод искать по имени символа, а не останавливаться.
5. **Прежний G4.8 противоречил R11.** «Включение — ≥ 1 `start()`» требовало пробного звука, который R11 запрещает. Исправлено: включение — 0 `start()`, первое листание после включения — ровно 1 `start()`.

## 4. Решения (приняты постановкой; менять нельзя, оспаривать — вопросом владельцу)

**R1. Точка запуска звука.** Звук вешается на `changeState === 'flipping'` (F4.2) плюс собственное `pointerup` для перетаскивания (F4.3, F4.7). На событие `flip` звук НЕ вешается: это конец анимации (F4.1). План называет событием синхронизации `flip` (`docs/BOOK-READER-PLAN.md:303`) — расхождение фиксируется в отчёте; `flip` остаётся за S3 (счётчик, позиция, `disabled`).

**R2. Направление листания** (в событиях его нет, F4.9) — порядок приоритета: (1) `pendingDir` = `-1`/`+1`, который ставят наши кнопки непосредственно перед `flipPrev()`/`flipNext()`; (2) для перетаскивания — знак горизонтального смещения (смещение влево — вперёд, вправо — назад); (3) иначе половина сцены по `pointerdown` (правая — вперёд); (4) иначе вперёд. `pendingDir` сбрасывается после использования.

**R3. Числа звука.** Вперёд: полоса 900–2600 Гц, центр `f0 = √(900·2600) ≈ 1530 Гц`, добротность `Q = f0/(2600−900) ≈ 0.9`. Назад: полоса 600–1800 Гц (`f0 ≈ 1039 Гц`, `Q ≈ 0.87`) и громкость 0.108 = 0.18 × 0.6. Огибающая: старт с громкости и `exponentialRampToValueAtTime(0.0001, now+0.06)`; ровно `0` в WebAudio нельзя — исключение. Буфер — 60 мс белого шума, создаётся один раз.

**R4. Состояние звука.** `localStorage['book.sound.v1']` = `'on'`/`'off'`. Если ключа нет — звук включён, кроме `prefers-reduced-motion: reduce` (тогда выключен по умолчанию). Явный выбор читателя главнее умолчания: при сохранённом `'on'` звук работает и под reduced-motion (`docs/BOOK-READER-PLAN.md:171`). G4.9 проверяет именно умолчание — на чистом хранилище.

**R5. Ограничитель.** Между стартами звука ≥ 120 мс (`lastPlayedAt`); он же снимает двойной звук из F4.6. Второй звук не откладывается, а не играет вовсе.

**R6. Контекст — только по жесту.** `new AudioContext` не выполняется ни при загрузке модуля, ни при открытии книги. Создание — ленивое, внутри обработчика того жеста, который требует звука: `pointerdown` сцены и кнопок «‹/›/Звук» (прогрев графа) либо первое листание (`changeState('flipping')`), если контекста ещё нет. Прогрев создаёт контекст и строит граф, но **не вызывает `start()`** — звука нет (R11); клик по переключателю вида и любая загрузка страницы контекста не создают. При `state === 'suspended'` — `resume()` с `catch`. Нет конструктора, конструктор бросил или упал сам `playFlip`/`warmAudio` → `fail(...)`, `audioBroken = true`, кнопка «Звук» получает `disabled` и `aria-pressed="false"`, книга листается дальше. Сохранённый выбор при отказе НЕ перезаписывается.

**R7. CSS — одна строка.** Нажатое состояние звука красится тем же правилом, что у переключателей вида (`book.css:52`): `[data-book] .book-tools [data-book-sound][aria-pressed="true"] { background: var(--paper-2); }`. Новых цветов, переходов, `@media print` и анимаций не появляется.

**R8. `site.config.json` не трогаем.** Флага звука в конфиге нет, §S4 его не требует, файл вне списка шага. Выключатель есть всегда.

**R9. Жизненный цикл звука.** `close()` отпускает звук: `audioCtx.close()` в `try/catch`, `audioCtx = null`, `noiseBuf = null`, `lastPlayedAt = 0`, слушатели `pointerdown/pointermove/pointerup` сняты. Повторное открытие создаёт контекст заново по жесту. Слушатели StPageFlip снимает `destroy()` из S3 — не дублируй.

**R10. Упрощённый режим §2.5 закрывается здесь, но с допустимым значением.** В настройках PageFlip: `flippingTime: prefersReduced() ? 1 : FLIP_MS` (FLIP_MS = 700, F3) и тени — `drawShadow: prefersReduced() ? false : true`, `maxShadowOpacity` остаётся SHADOW_OPACITY. Обоснование значения 1: конструктор отвергает ≤ 0 (F4.10), 1 мс даёт длительность анимации порядка кадра. Значение читается при монтировании/remount; слушатель смены медиазапроса в рантайме не нужен. Если S3 уже сделал эту ветку — не дублируй, отметь в отчёте.

**R11. Пробный звук при включении не играем.** Включение только создаёт контекст (жест); звук появляется на первом листании. Иначе счётчики G4 перестают означать «один звук на листание».

- **S8.** Контекст просят создать при импорте модуля или до жеста: запрещено, переписать на ленивое создание (R6).
- **S9.** Хочется передать `flippingTime: 0` или иное значение ≤ 0 «как в документе»: стоп — конструктор бросает `Invalid flipping time` (F4.10), допустимый минимум 1 (R10).

## 10. Вопросы

**В1. Кто подтверждает звук на слух?** Исполнитель — агент на Windows без слуха: G4 доказывает существование сигнала, его частоту, громкость, момент старта и глушение, но не «похоже на шелест бумаги». Принят вариант A: шаг закрывается по G4, тембр слушает владелец на приёмке — цена: неудачный тембр всплывёт позже и правится одной строкой чисел R3, зато шаг не стоит. Вариант B (держать шаг открытым до прослушивания) не выбран: он блокирует S5 и S6. Молчаливая подмена («звук есть, значит слышно») запрещена.

**В2. Что делать с бюджетом 20 КБ?** На HEAD `book.js` + `book.css` = 29 390 байт, то есть бюджет 20 480 превышен уже после S3. Принят вариант A: S4 только меряет прирост (ожидание ≤ 1,5 КБ), порог и его приведение в `verify.mjs` — дело S6, где решается, что ужимать; в отчёте долг называется числом. Вариант B (уложиться в 20 КБ уже в S4) не выбран: он требует сжатия чужого кода S2/S3 внутри шага звука и рискует регрессом нарезки текста.

## 11. Ревью (обязательно)

Шаг закрывает не исполнитель. После кода и зелёных гейтов работа уходит на независимое ревью роли `reviewer` (скилл `pipeline-reviewer`): он читает план §S4 (`docs/plans/1-book-reader.md:89-96`), `docs/BOOK-READER-ESENIN-PLAN.md` §7 и §8 п.3, `docs/BOOK-READER-PLAN.md` §2.5 и фазу 4, и код — а не отчёт исполнителя.

- Вердикт: **APPROVE** или **REQUEST_CHANGES**, третьего нет.
- При REQUEST_CHANGES шаг остаётся открытым: находки правятся в тех же двух файлах, гейты G0-G5 прогоняются заново, ревью повторяется.
- Строка «ЗАКРЫТ» в журнале плана и коммит закрытия — только после APPROVE, их делает страж конвейера, не исполнитель.
- Ревьюер обязан проверить отдельно:
  1. точка запуска звука — `changeState('flipping')` плюс `pointerup` перетаскивания, и звук перетаскивания выдаётся только когда лист действительно переворачивается (`getPosition().x <= 0`); на `flip` звука нет (F4.1-F4.3), расхождение плана названо в отчёте;
  2. числа и умолчания: буфер 60 мс, вперёд 900–2600 Гц и 0.18, назад ниже и тише, ограничитель 120 мс, ключ `book.sound.v1`, reduced-motion выключает по умолчанию (R3-R5);
  3. «`AudioContext` только после жеста» доказано счётчиками G4.1 и G4.14, а звук — по факту переворота (G4.15, G4.16), а не чтением кода (R6): при загрузке — 0, прогрев на `pointerdown` сцены и «‹/›/Звук» без `start()`, клик по переключателю вида — 0;
  4. двойного звука нет — интервалы G4.7 приведены числами;
  5. отказ WebAudio — G4.10: книга листается, `console.warn`, кнопка `disabled`, исключений 0, пустого экрана нет;
  6. упрощённый режим: `flippingTime` равен 1, а не 0, и `drawShadow: false` при reduced-motion (G4.12, R10, S9);
  7. жест G4.6 действительно переворачивает лист: в отчёте есть позиция листа в момент отпускания и факт смены индекса страницы, а не только число `start()`;
  8. прирост размера измерен от 29 390 байт (а не от устаревших 18 258), долг бюджета назван, чужой код S3 цел;
  9. контракт S2/S3 цел: атрибуты и ключи из §5, `src/book/stpageflip.js` не тронут (`git show --stat`), `package.json` без новых зависимостей, звуковых файлов и тегов `audio` нет (C3);
  10. коммит содержит только `src/book/book.js` и `src/book/book.css` (`git show --stat`), `data/updated.json` и `docs/reviews/*.md` в него не попали, журнал плана не правился, в отчёте есть строка про слышимость (В1).
