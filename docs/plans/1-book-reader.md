# План 1. Книжный виджет в библиотеке Есенина

Конституция: docs/CONSTITUTION.md

> Дата: 03.11.2026. Репозиторий: `C:\Users\malik\esenin-dashboard`, домен poet-esenin.ru.
> Основание: `docs/BOOK-READER-ESENIN-PLAN.md` (план работ по этому репозиторию) и
> `docs/BOOK-READER-PLAN.md` (общие решения, сравнение библиотек). Код пишется только
> по шагам этого плана, шаг за шагом, с ревью между шагами.

## Цель

На poet-esenin.ru у 17 нестихотворных произведений библиотеки (3 повести и рассказа,
10 статей, 4 автобиографии — всё, что длиннее 1 500 знаков) появляется кнопка «Режим книги»:
текст открывается постранично, как в печатной книге, с номерами страниц, перелистыванием
листом со звуком, выбором одной страницы или разворота. По умолчанию страница произведения
остаётся ровно такой, как сейчас, — обычный текст с прокруткой; книжный режим включается
кликом, помнит выбор и полностью откатывается. `npm run verify` — 0 ошибок, 0 предупреждений.

## Контекст

Проверено в репозитории на 03.11.2026, `master` = `fd0fe67`.

- Текст произведения выводится одним блоком: `scripts/build.mjs:1183` —
  `<div class="poem">${esc(w.text)}</div>`; тулбар кнопок — `build.mjs:1174–1182`
  (A−, A+, «Режим чтения», «Без оформления», «Печать», «Копировать»).
- Обработчик кнопок — `src/app.js:241–271`; книжного кода нет ни в `src/`, ни в `dist/`.
- Ассеты копируются вручную (`build.mjs:1770–1772`), версия одна на три файла
  (`build.mjs:134–136`), подставляется как `?v=` (строки 395, 409, 485).
- Гейты текстов произведений — `scripts/verify.mjs:361`; книжных гейтов нет.
- Секции `reader` в `site.config.json` нет.
- Материал неоднороден: у автобиографий абзацы разделены переводом строки, а не пустой
  строкой; в «Железном Миргороде» части `I–IV` и подзаголовки капслоком («ЭЛИС-АЛЕНД»,
  «НЬЮ-ЙОРК», «БРОДВЕЙ»); в «У белой воды» части «1», «2», «3» отдельными строками;
  в «Ключи Марии» и «Ярославны плачут» — цитаты стихами внутри прозы. Наивное
  `split('\n\n')` портит 8 текстов из 25.
- Кнопку получают 17 текстов из 25; восемь коротких (197–1 190 знаков) остаются без книги.

## Разведка

Артефакт: `docs/research/1-book-reader-prior-art.md` — таблица кандидатов (лицензия, звёзды,
дата, что даёт, чего стоит, вердикт), проверки на прототипе и итог.

Решение: go. Анимацию листа берём у StPageFlip (`page-flip.browser.js` 2.0.7, MIT, 44 КБ,
10,2 КБ gzip), вендорим файлом в репозиторий; постраничную разбивку, нарезку по `Range`,
номера, тулбар, звук, доступность, печать и гейты пишем свои.

## Допущения

1. Порог «≥ 1 500 знаков» и список жанров выбраны нами и живут в `site.config.json`
   (`reader.book.genres`, `reader.book.minChars`): владелец сможет поменять охват без нового
   плана, шаги от этого не меняются.
2. Версия библиотеки пинится на 2.0.7 (последняя в npm, 04.2021); обновление — отдельная
   задача, не часть этого плана.
3. Звук — синтез WebAudio, звуковых файлов в репозитории не появляется.
4. Перенос в `bunin-site` и в скаффолд `writer-site-factory` — после приёмки здесь, вне
   шагов этого плана.
5. Приёмка на живом домене делается после фазы выкладки; до неё шаги проверяются на
   локальной сборке `npm run build` + `npm run verify`.

## Шаги

### S1. Разметка прозы: абзацы, части, даты и стихотворные цитаты (1,5 дн)

- 17 текстов библиотеки собираются в абзацы с типами `p`, `verse`, `part`, `date`, `head` без потери единого знака текста.
- Файл: `scripts/build.mjs`, `scripts/verify.mjs`, `site.config.json`, `data/book-overrides.json`
- Тесты/гейты: `npm run build` → в отчёте строка «book: 17 текстов, 0 расхождений»; `npm run verify` → 0 ошибок / 0 предупреждений; `node -e` сверка суммы текста абзацев с `chars` из `data/works.json` → 0 расхождений
- Готово = в собранных страницах 17 текстов абзацы размечены `<p>`, в «Железном Миргороде» части `I–IV` и подзаголовки капслоком стоят отдельными блоками, в «У белой воды» части «1», «2», «3», в автобиографиях каждый абзац — свой `<p>`, цитаты стихами в «Ключи Марии» и «Ярославны плачут» не слиты в прозу, сумма текста равна `chars`; постановка в `docs/prompts/` прошла `check_task_prompt.py`
- Важно: стихи и поэмы (388 текстов) не трогать, `white-space: pre-wrap` у них сохраняется; из текста ничего не выбрасывать, включая строки-цифры
- Риск: normal

### S2. Кнопка «Режим книги» и ленивый запуск книжного режима (1 дн)

- Кнопка у 17 текстов открывает постраничный вид с номерами «N из M»; до клика `book.js` не загружается.
- Файл: `scripts/build.mjs`, `src/app.js`, `src/book/book.js`, `src/book/book.css`, `site.config.json`
- Тесты/гейты: `npm run verify` → 0/0 (гейт «book.js нет как `<script src>` в HTML» добавляет S6 — см. R1 постановки S2); `curl -s http://localhost:4173/works/бобыль-и-дружок.html` → в ответе нет `book.js`; DevTools → Network → после клика один запрос `/book/book.js?v=…`
- Готово = кнопка есть у 17 текстов и отсутствует у 8 коротких и у стихов; клик открывает книгу с номерами страниц и кнопками «Одна страница»/«Разворот», «Обычный текст» возвращает исходную вёрстку на том же месте чтения, выбор и позиция живут в `localStorage`; постановка в `docs/prompts/` прошла `check_task_prompt.py`
- Важно: `.poem` не переписывать в разметке сборки — книжный вид строится из него в браузере
- Риск: normal

### S3. Лист и разворот на вендоренном StPageFlip (0,5 дн)

- Перелистывание листом с изгибом мышью, пальцем и кнопками; разворот и одна страница переключаются по ширине сцены.
- Файл: `src/book/stpageflip.js`, `src/book/book.js`, `src/book/book.css`, `scripts/build.mjs`, `scripts/verify.mjs`
- Тесты/гейты: `npm run verify` → 0/0 и зелёные книжные гейты (файл в `dist/book/`, размер ≤ 50 КБ, заголовок MIT, `<canvas>` в HTML — 0); ручной прогон в Chrome на «Бобыле и Дружке» исполнителем → листание вперёд/назад, после ресайза позиция сохраняется; Safari — владельцем на macOS до закрытия S6 (решение владельца A от 04.11.2026)
- Готово = книга инициализируется из `.poem[data-book-source]`, `getPageCount()` совпадает с числом нарезанных страниц, перелистывание не теряет текст (сумма текста страниц равна источнику), при ошибке загрузки библиотеки читатель видит обычный текст и сообщение в консоли, а не пустой экран; постановка в `docs/prompts/` прошла `check_task_prompt.py`
- Важно: библиотека — UMD-файл с глобалом `window.St.PageFlip`, а не ES-модуль; грузить его один раз промисом
- Риск: normal

### S4. Звук перелистывания (0,5 дн)

- Перелистывание озвучено коротким синтезированным шорохом, вперёд и назад по-разному, с выключателем.
- Файл: `src/book/book.js`, `src/book/book.css`
- Тесты/гейты: `npm run verify` → 0/0; ручной прогон: звук совпадает с анимацией, при `prefers-reduced-motion` выключен, двойного звука при быстром листании нет, `AudioContext` создаётся только после клика
- Готово = звук синтезируется WebAudio (файлов .mp3/.wav в репозитории нет), выключатель «Звук» помнит выбор в `localStorage`, при отказе WebAudio книга продолжает листаться молча; постановка в `docs/prompts/` прошла `check_task_prompt.py`
- Риск: normal

### S5. Тулбар книги, клавиатура и анонсы для скринридеров (0,5 дн)

- Страница произведения проходится в книжном режиме без мыши, скринридер объявляет «Страница N из M».
- Файл: `src/book/book.js`, `src/book/book.css`
- Тесты/гейты: `npm run verify` → 0/0; ручной прогон с клавиатуры только (Tab, стрелки, Home/End, Esc) на «Железном Миргороде»; NVDA в Chrome → анонс номера страницы при листании
- Готово = работают ←/→, Home/End, Space; Esc и «Обычный текст» выходят из книги; `role="region"`, `aria-roledescription="книга"`, `aria-live` с номером страницы; фокус не теряется при перелистывании; постановка в `docs/prompts/` прошла `check_task_prompt.py`
- Важно: номера страниц в вёрстке помечены `aria-hidden`, чтобы не читались дважды
- Риск: low

### S6. Печать, отказы и книжные гейты в verify (0,5 дн)
