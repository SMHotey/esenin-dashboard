# Есенин — дашборд-лендинг

Статический просветительский сайт о Сергее Александровиче Есенине (1895–1925): обзорная биография, статьи о периодах жизни, люди вокруг поэта, полная библиотека произведений с каталогом и научная библиография.

**Стек:** статическая генерация на Node.js без зависимостей; данные — JSON + Markdown; поиск и фильтрация — на клиенте. Сборка кладёт готовый сайт в `dist/`.

---

## Быстрый старт

```bash
npm run build     # собрать сайт в dist/
npm run serve     # локальный сервер на http://localhost:4173
```

Или одной командой: `npm run dev`.

Проверка внутренних ссылок:

```bash
npm run check
```

## Как обновить библиотеку

Тексты берутся из Викитеки (общественное достояние).

```bash
npm run import:genres   # обновить карту жанров
npm run import:works    # дозагрузить страницы в кэш
npm run build:works     # пересобрать data/works.json
npm run build
```

Импортёр кэширует сырой вики-текст в `data/raw-cache.json`, поэтому повторный запуск не дёргает API за уже загруженными страницами. При большом объёме Викитека отвечает `429` — скрипт делает retry с экспоненциальной задержкой.

**Важно:** после импорта проверьте несколько произведений вручную. Автоматическая очистка разметки покрывает основные шаблоны (`{{poem}}`, `{{poemx}}`, `{{v}}`, `{{f1}}`, `<poem>`), но новые шаблоны могут потребовать правки `scripts/clean.mjs`.

## Как добавить статью

1. Создайте `content/my-article.md` с frontmatter:

```md
---
title: "Название"
slug: my-article
kind: period
excerpt: "Короткое описание для карточки и поиска."
---

Текст статьи. Поддерживаются `##` заголовки, списки, цитаты и ссылки.
```

2. Добавьте файл в массив `articleFiles` в `scripts/build.mjs`.
3. Пересоберите сайт.

## Контентные правила

- **Факты.** Каждое утверждение должно опираться на источник. Спорные сюжеты выносятся в `data/versions.json` и не подаются как установленные.
- **Тексты.** Произведения — общественное достояние; у каждого указана страница-источник в Викитеке.
- **Фотографии.** Только Wikimedia Commons (Public Domain / свободная лицензия) с атрибуцией. Музейные и газетные изображения не используются без письменного разрешения.
- **Научные работы.** Публикуются только метаданные и краткие аннотации; полные тексты не размещаются.
- **Персоны.** У каждой карточки — роль, годы и источник; в разделе «Женщины» факты, посвящения и версии разделены.

## Деплой

Сайт полностью статический. Подойдёт любой хостинг статики (GitHub Pages, Netlify, Cloudflare Pages, nginx).

1. Укажите боевой домен в `site.config.json` (`siteUrl`) — от него зависят `sitemap.xml`, `robots.txt` и OpenGraph.
2. Выполните `npm run build`.
3. Загрузите содержимое `dist/` на хостинг.
4. Настройте `404.html` как страницу ошибки.

Для nginx:

```nginx
root /var/www/esenin/dist;
location / { try_files $uri $uri/ $uri.html =404; }
error_page 404 /404.html;
```

## Ограничения текущей версии

- Поиск по каталогу ищет по названию и первой строке, а не по всему тексту произведений (сделано ради скорости на мобильных).
- Полнотекстовый поиск по всем 410 текстам можно включить, расширив `search.json` и индекс в `scripts/build.mjs`.
- Нет CMS-админки: контент правится в JSON/Markdown и пересобирается. Это сознательный выбор в пользу скорости и безопасности; при необходимости подключается headless CMS.
- Английская версия не сделана, но в данных и URL заложена возможность i18n.
- `data/raw-cache.json` не коммитится (большой); при первом импорте скачается заново.
